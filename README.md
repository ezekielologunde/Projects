# Projects Vault (Obsidian)

This repository is an **Obsidian vault** — a knowledge base for all projects. Open it in Obsidian with **Open folder as vault** and everything (templates, daily notes, attachments) is pre-configured via the included `.obsidian` settings.

## Structure

```
00 - Home/       Dashboard and entry point (start at "🏠 Home")
01 - Inbox/      Quick capture + daily notes; process into projects
02 - Projects/   One knowledge-base folder per project:
                   Research/  Meeting Notes/  Resources/  Archive/
03 - Areas/      Ongoing responsibilities with no end date
04 - Resources/  Cross-project reference material
05 - Archive/    Completed or dormant projects
99 - System/     Templates and attachments
```

## Conventions

- Every project has a `📌 <Project Name>.md` index note created from `99 - System/Templates/Project Template.md`.
- Tags: `#project/<name>`, `#status/active|on-hold|done`, `#type/research|meeting|idea|reference`.
- Attachments land in `99 - System/Attachments`; new notes default to `01 - Inbox`.
